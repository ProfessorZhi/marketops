# 巴黎室内运动场馆 · 0.6.5 跑测结果（2026-10-27）

题面沿用 [`docs/benchmarks/paris-indoor-062/TASK.md`](../paris-indoor-062/TASK.md)：巴黎市（INSEE 75）所有室内
运动场馆，找到能决定或直接运营场馆的人的有效邮箱，排除 `info / admin / book` 一类前台与工单地址。
本轮不缩小范围、不补来源，只回答一个问题：**0.6.5 在一道真题上能不能把 953 家机构干净地跑完并交付。**

一句话结论：**能跑完、对得上、成本可控；但 0.6.5 交付前还有四个可复现的缺陷，其中一个会让分片崩溃重启。**

种子是上一轮（0.6.2 巴黎题）合并出来的机构清单，1,064 行，`pool(into="orgs")` 去重后 **953 家机构**，

953 家之外（例如更多联合会、更多区属协会）没有覆盖，广度指标只对这份池子成立。

## 6. 0.6.5 的四个缺陷（均可复现）

### D1 分片并发写 `contacts.csv` 会互相抢临时文件

四个分片在这一轮**全部**至少崩过一次：

```text
FileNotFoundError: [Errno 2] No such file or directory:
  '.../paris-indoor-065/contacts.tmp' -> '.../paris-indoor-065/contacts.csv'
```

`mo_workspace.write_csv` 用固定名 `contacts.tmp` 写临时文件再 `os.replace`，多个分片同时 flush 时
一个进程把别人的临时文件 rename 走了。supervisor 各重启 1–2 次，数据没丢（重启后从磁盘续跑），但两个副作用：

- 每个分片的 `progress.usd_this_run` 在重启后重新累加，四片相加读到 **$53**，实际追加账 **$18.87**；
- `progress.flow.done` 会超过该分片应有的机构数（看到 `761 > 238`），重启后按磁盘判定「已完成」把整批快速跳过。

修法建议：临时文件名带 pid/分片号（`contacts.<shard>.tmp`），或直接改用 `O_TMPFILE`/每片写自己的分片文件再合并。
在修好之前，**不要用 `progress.usd_this_run` 做成本读数**，用 `costs.jsonl` 的追加账。

### D2 说明页并列两个 A/B 口径，没有标注

同一页上：

- 「有 A+B 的机构占比」= **14.5%**（138 家，确认口径，排除待复核）；
- 对账行的「A 108 + B 136」= **244 家**（含待复核的最佳等级）。

两个数都对，但并排放着、都不写口径，读的人会当成矛盾。建议在一行里写清
`A+B 机构（含待复核）244 / 确认 138`。

### D3 共用地址没有进待复核

1,244 条确认 A/B 里，**446 条**的 `also_on` 非空（该地址同时挂在别的机构下），但 `review` 为空。
最多的一条地址挂在 **5 家**机构下，全部按 A 交付。对照：本轮另有 294 条同因被正确推进了待复核
（`address also listed for N other organisations`），说明规则存在但没有覆盖全部行。

建议：只要 `also_on` 非空且不属于「同一运营方的多场馆」，一律进待复核，或降一档。

### D4 他站页面的 A/B 没有拦住

67 条确认 A/B 的 `page_on_org_site=no`，来源是文档分享站、行业新闻页、别家域名下的 PDF。
同因被正确拦下的有 273 条（`neither the page nor the address is on the organisation's own site` /
`page on another site, organisation not named next to it`），同样是覆盖不全。

### D5 A 级里有 34 条没有具名人员

确认 A 418 条中，`person` 为空 34 条、`role` 为空 31 条。题面与分级契约都要求
**A = 具名人员 + 岗位 + 工作邮箱**，这 34 条按定义应该是 B（岗位信箱）或 C。示例（地址已打码）：

| 机构类型 | 地址 | 判级理由原文 |
|---|---|---|
| 区属体育馆 | `p***@paris.fr` | `jev A p 0.44; named p 0.90`，岗位是「某辖区主管」 |
| 私立学校 | `s***@<校名>.com` | 页面来自文档分享站，学校不是场馆运营方 |
| 协会 | `c***@gmail.com` | `page on another site`，却是 A |

这 34 条与 D3、D4 有重叠：同一条地址既没有具名人员、又来自他站、又挂在多家机构下，却一路判到 A。
