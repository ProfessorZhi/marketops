# docs/runs/ — 公开侧只放脱敏过程记录

真实测试 Run 的逐条产物（机构明细、联系人、读页记录、逐次成本、导出工作簿、抽检证据）
**不在这个仓库**。它们的唯一写入权威是私有仓：

```
https://github.com/ProfessorZhi/marketops-session
  runs/<benchmark>-<插件版本>-<日期>/
```

本目录只放**可以公开的过程记录**：题面的版本、判定、指标口径、失败分布、通用缺陷与
复现方式。凡是第三方姓名、工作邮箱、电话、原始页面正文，一律不进这里。

## 为什么这样分

| | 本仓（公开） | `marketops-session`（私有） |
|---|---|---|
| 产品源码、插件、Skill、测试 | ✅ 唯一权威 | ❌ |
| benchmark 题面 `docs/benchmarks/<题>/TASK.md`、基线口径 | ✅ | 引用 |
| Run 的逐条数据与真实联系人 | ❌ 绝不 | ✅ 唯一权威 |
| Run 的脱敏过程记录 | ✅ | 原文在此 |
| 超大页面镜像 / 原始语料 | ❌ | ❌（运行机磁盘，以哈希与指针登记） |

## 命名

```
docs/runs/<benchmark>-<插件版本>-<日期>.md      # 脱敏过程记录
```

私有仓对应目录：

```
runs/<benchmark>-<插件版本>-<日期>/            # 完整产物
```

两边同名，便于互相定位；一边是摘要，一边是全量。

## 写一条公开记录的检查表

- [ ] 只写机构级事实；联系人只报**计数与分布**，不写值。
- [ ] 每个指标写清分子/分母与口径（工作簿口径 ≠ 事后过滤样本）。
- [ ] 失败不隐藏：达不到门槛就写未通过，并给出通用缺陷与复现方式。
- [ ] 不在公开记录里出现本机绝对路径中的个人信息、token 或凭据。
- [ ] 链接到私有仓的目录名（不带 token 的 URL），不复制其内容。
