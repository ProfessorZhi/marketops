# MarketOps 研究插件

统一入口：[MarketOps Research Assistant](marketops-research-assistant/README.md)。一个受管 MCP、17 个研究 Skills、五个项目的调用、集中证据与数据、Excel 交付，以及跨任务经验召回和反馈。

TinyFish 和 SerpApi 官方 MCP 客户端直接随包。[四账户指引](marketops-research-assistant/references/FOUR_ACCOUNT_START.md)说明 Serper、SerpApi、TinyFish、TypeSafe 的注册、Key 与赠金；Crawl4AI 在本地运行。

Windows 一键安装和 Linux 入口见 [START_HERE](marketops-research-assistant/START_HERE.md)。机器相关连接器在客户电脑生成。真实可用性和研究效果以对应构建的验收回执为准。

其余 `codex/`、`workbuddy/` 和独立 provider 包保留作历史/开发参考；客户使用统一安装包，无需把旧连接器全部装入宿主。

保留的 `codex/marketops-research-starter`、`workbuddy/tinyfish`、`workbuddy/crawl4ai` 是历史独立候选，不是当前统一安装入口。
