# 研究工作簿与交付核验

`marketops_export_xlsx` / `marketops_handoff` 从同一数据库快照生成真实 XLSX，并保留对应 CSV 和 SHA-256 manifest。

当前九个工作表：客户总表、联系人路线、排除与待确认、证据索引、本轮说明、场地与资产、人员岗位、来源与查询、候选数据审计。`marketops_evidence_workbook` 是独立的五表证据视图，不是另一份业务事实库。

- 联系值必须在相应来源材料中出现，附逐字段引文；组织、场地、岗位与联系方式之间的语义关联还需复核。
- 原始响应、浏览器渲染 HTML、供应商返回的 HTML、Markdown 和 Jev 判断分别标明，不能互相冒充。
- 所有输入目标保留处置：研究结果、HOLD、排除、重复或未完成。未知不写成零，正文不足不补猜测邮箱。
- 场地数、组织数、路线数分别按唯一键计数；一组织多场地不能重复计算组织。
- 外部字符串以文本写入，保留前导零，拒绝公式注入；工作簿要实际打开并核对表数、行数和字段。
- 导出文件不可就地覆盖；更正生成新交付 ID。文件存在不代表业务完成，回执分别报告技术完整性、证据缺口和任务范围。
- 研究评级保持供复核状态，不因模型回答或字面匹配自动批准正式 A/B/C/D，也不授予发送权限。

数据根保存事实、来源和历史；Excel 是该快照的可审阅视图。经验汇总另附实际记录与反馈，不根据文件数量推算提效。
