# 客户安装入口

当前安装与启动流程统一维护在 [客户快速开始](CUSTOMER_QUICKSTART.md)。

Windows 解压源码包后双击 `Install.cmd`；Linux 使用 Python 3.12 运行 `install.sh`。安装器准备 MarketOps、内嵌 TinyFish/SerpApi MCP 客户端、四家必备接入与可选的 DeepSeek、本地 Crawl4AI，生成本机宿主配置与 `START_HERE.md`。

客户本人完成[四账户注册、申请 API Key、查看新用户额度](FOUR_ACCOUNT_START.md)，在本机隐藏输入保存到系统凭据库。研究数据目录和独立经验汇总文件由客户选择；升级保持这些数据和配置。

安装目录的 `START_HERE.md` 给出 Codex 添加和安装、WorkBuddy 本机导入、Claude Code 启动的具体命令和位置。安装后新建会话运行一个小范围真实任务，核查有效结果、证据、Excel 和经验复用。安装回执中的未验证状态必须保留，不能用离线测试代替客户宿主验收。
