# 安全与付费边界

这是可发给用户试用的工具包，不是生产权限系统。**提示词或 Skill 中说“不要付费”不构成技术层面的禁止。** 在启动实际 Provider 之前，用户应在服务控制台核实套餐/余额、实际单价、限额和自动充值设置，并只对具体任务授权调用。

1. **凭据**：用户自己申请 Serper、Crawl4AI、TinyFish、TypeSafe 的 Token。仓库仅保存变量名/示例，不保存真实密钥；不要把密钥复制进聊天、日志、截图、PR、ZIP 或共享 Skills。
2. **使用场景**：只访问允许的公开网站；尊重适用条款、robots 与隐私法规；遇到验证码、访问限制和登录墙时停止，不能让代理自动绕过。
3. **权限**：不在东京开发者账户或共享 `member-b` CC 环境运行客户研究；本地 Codex/WorkBuddy 的文件/Bash 权限由其宿主沙箱控制，不会因 MCP 的 Workspace 限制自动收窄。
4. **客户数据**：记录 URL、检索和抓取时间、原始事实引用、验证状态。不采集非必要个人信息，不上传客户私密数据库到外部网页自动化服务。
5. **供应商 Key 不共享**：若客户直接连接第三方官方 MCP，则调用在客户自己名下计费；若未来走 MarketOps 受管网关，凭据仅由服务器持有，按 Run 独立授权。
6. **浏览器工具**：TinyFish `run_web_automation`、Crawl4AI 浏览器抓取可能产生费用。Crawl4AI Cloud MCP 还提供 `topup`、`recharge`、`spend_cap` 等账单管理工具；不能默认赋予研究 Agent 这些修改账单的能力。
7. **高风险操作**：任何充值、提高限额、购买方案、自动续费、登录第三方账户、外联/发邮件/提交表单，必须经过单独的用户明确确认；首版不提供这类自动化。
8. **证据**：Serper 搜索摘要和地图信息只用于发现。真实事实应有原网站、公开文档或其他可信来源支持；抓到的验证码页不可当证据。
9. **输出**：试用阶段默认为人工检查候选 CSV；不得把 `unknown`、推测角色或推断邮箱写成已确认事实。
10. **隔离验收**：上线团队版前必须测试另一个用户/工作区无法访问本用户的数据库、导出文件或凭据，且没有任意宿主路径读写工具。

如不确定工具是否收费，先不要执行，打开服务官方控制台核对。
